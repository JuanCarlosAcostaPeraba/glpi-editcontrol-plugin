# Support

Use Issues for bugs and proposals, in Spanish or English. Include plugin, GLPI,
PHP and database versions, mode, takeover policy and relevant plugins. Reproduce
with fictitious data. Attach sanitized logs only; never publish passwords, cookies,
tokens, private keys, personal data or real ticket content.

Security reports belong in private reporting (SECURITY.md). Community support is
best effort, without an SLA. For an urgent rollback, deactivate the plugin in GLPI.
Deactivation preserves its tables and audit; uninstallation removes plugin data.
See docs/MANTENIMIENTO.md and back up before uninstalling.
