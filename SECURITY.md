# Security policy

Security fixes target the latest published release; older releases are not maintained.

Use [GitHub private vulnerability reporting](https://github.com/JuanCarlosAcostaPeraba/glpi-editcontrol-plugin/security/advisories/new).
Include affected versions, impact and minimal reproduction with fictitious data.
Do not publish credentials, session tokens, real tickets, personal data or exploit
details in public issues. Reports are assessed as availability allows; no response
SLA is guaranteed.

This plugin supplements GLPI permissions. Direct SQL and some third-party paths
are outside its protection. API, CLI and self-service exemptions are documented
in README.md and docs/LIMITACIONES.md.
